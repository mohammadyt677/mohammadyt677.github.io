✨ What This App Does For You

Rhythm games each use their own file format, and moving a chart from one game to another usually means starting over from scratch. Malody_osu_con removes that problem. It reads a beatmap from one game, rebuilds it in the format of the other, and hands you a file that opens normally.

The conversion works in both directions. An osu!mania chart can become a Malody .mcz package that you can open in the Malody editor and change as much as you like. A Malody chart can become an .osz package that osu! recognises straight away.

Because the tool rebuilds the files from the actual note data rather than a simple rename, your timing, note positions, key count, scroll speed settings, and audio references stay intact. Custom sound effects carried by the original map are preserved as well.

Not everyone likes to work the same way, so the tool gives you four separate entrances. They all produce identical results, so pick whichever feels most comfortable.

⚙️ Step-by-Step: Your First Conversion

  1. Find your beatmap file. osu!mania charts end in .osz. Malody charts end in .mcz. Both are single files that hold the chart, the music, and any extra sounds.
  2. Open the converter. Launch the graphic window, or open the web page version if you prefer.
  3. Choose your direction. If you are starting from an .osz file, the tool will produce a .mcz. If you are starting from a .mcz, it will produce an .osz. The window picks the correct direction automatically once it sees your file.
  4. Confirm the output folder. By default the new file is saved in the same folder as the original. You can point it somewhere else if you like, for example a dedicated folder for converted maps.
  5. Press convert and wait. A single chart takes only a moment. A very large map with many custom sounds takes slightly longer, but it is still quick.
  6. Test the result. Open the new file in the target game. In Malody, the converted map appears as an editable chart. In osu!, the converted package shows up in your song list like any other download.

💡 Tips for Best Results

  • Keep a copy of the original file before converting. That way you can always start again if you want to try different settings.
  • Leave the beatmap in its downloaded state. Renaming an .osz file to .zip and unpacking it is not necessary and can confuse the tool.
  • Convert one chart at a time when you are learning. Once the process feels familiar, you can batch several files through the command line.
  • After converting, open the map in the game to double-check that the audio lines up. This takes a few seconds and saves surprises later.

🛠️ Troubleshooting

Windows shows a warning when I open the app. This is a standard safety message for smaller independent software. Choose the option that lets you continue, and the program will start normally.

Nothing happens after I drop a file. Check the file ending. The tool accepts .osz and .mcz files. Files with other endings, or folders, are ignored.

The converted map looks empty in the game. Make sure you placed the finished file in the correct song folder for that game, and that you did not rename its ending.

The music is missing. Some beatmaps reference an audio file that was not included when the map was created. In that case there is nothing for the converter to carry across, and adding your own audio in the Malody editor solves it.

Conversion seems slow. Maps with lots of custom sound files take longer because every sound is copied into the new package. Give it a moment and leave the window open.
